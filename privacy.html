Privacy Policy

Effective date: October 22, 2026

This policy applies only to Gamit Backups, a personal utility intended to store encrypted backup files for the Gamit productivity application in the owner's Google Drive.

Google user data accessed

Gamit Backups requests only the Google Drive drive.file scope. The utility may create, list, download, update, and delete files and folders that it creates or that the user explicitly opens with it. It does not request unrestricted access to other Google Drive files.

How data is used and stored

Google Drive access is used solely to transfer and manage encrypted Gamit backup files in a private folder controlled by the user. OAuth credentials are intended to be stored as protected configuration and are not included in backup files, public pages, source control, or application documentation.

Sharing

Google user data is not sold, used for advertising, or shared with third parties. Backup files remain in the user's private Google Drive unless the user independently changes their sharing settings.

Deletion and retention

The utility may delete backup files it created as part of an explicitly configured retention policy. The user may also delete the files or folder directly in Google Drive at any time.

Revoking access

The user can revoke access at any time from the security and third-party connections settings of their Google Account. Revocation prevents future access but does not automatically delete files already stored in Google Drive.

Current status

The integration is being prepared and is not yet operational. No automated backup is currently running.
