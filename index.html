Gamit Backups

Gamit Backups is a personal backup utility for the Gamit productivity application.

Purpose

The utility is intended to upload encrypted Gamit backup files to a private folder in the owner's Google Drive. It is not the Gamit application and does not make Gamit or its data publicly accessible.

Google Drive access

The utility requests only the drive.file scope. This permits it to create and manage files that it creates or that the user explicitly opens with it. It does not request unrestricted access to all files in Google Drive.

The integration is currently being prepared and is not yet operational. Automated backups are not currently running.
